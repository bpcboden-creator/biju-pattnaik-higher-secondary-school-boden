# Biju Pattnaik Higher Secondary School, Boden — Free Website

This is a static, mobile-friendly school website. It requires no database and no paid software.

## Files
- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — mobile menu and current year

## Free publishing
### GitHub Pages
1. Create a free GitHub account.
2. Create a new public repository.
3. Upload the three website files.
4. Open Settings → Pages.
5. Select the `main` branch and `/root` folder.
6. GitHub will provide a free `github.io` website address.

### Netlify
You can also upload the website folder to Netlify's free hosting and receive a free `netlify.app` address.

## Editing
All school text is inside `index.html`, so notices, events, admission information and contact details can be updated without a database.
